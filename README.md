# NetPresence

Instant, everyone-at-once classroom roll call over Bluetooth. A student taps **Mark me present**; the phone
advertises a random ID and listens for neighbours' signal strength (RSSI); the server builds a proximity graph and
floods trust outwards from the benches the teacher personally verified. Nobody has to be heard by the teacher's phone,
and nobody can mark attendance from the corridor or from home.

The original acoustic (FSK tone) system is kept as the baseline arm (`/api/acoustic`, "Acoustic (v1)" tab) so the two
approaches can be compared on real phones.

**Read first:** [`docs/V2.md`](docs/V2.md) (design, protocol, limits) and [`mobile/README.md`](mobile/README.md) (what is and is not verified).

## Layout

| Path | What |
|---|---|
| `backend/` | FastAPI + MongoDB. `app/services/graph.py` is the engine; `app/routers/` v2 (`devices`, `sessions`) and v1 (`acoustic`). |
| `backend/sim/` | Monte-Carlo classroom simulator, 93-student acceptance study (`orientation.py`), virtual-phone end-to-end driver (`e2e.py`). |
| `backend/tools/` | `fit_pathloss.py` (calibrate from real RSSI), `dev_server.py` (in-memory API), `ui_e2e.py` (browser test), `make_vectors.py`. |
| `frontend/` | React teacher console (start, live check-ins, seed verification, headcount, review queue) + acoustic v1 UI. |
| `mobile/core/` | TypeScript protocol core (signing, RSSI aggregation, session flow) with unit + live tests. |
| `mobile/app/` | React Native shell and native modules (Kotlin / Objective-C). **Device-untested.** |
| `docs/test-vectors.json` | Cross-language signed-message vectors generated by the server code. |

## Run it

```bash
# backend (needs MongoDB, or set NP_INMEMORY_DB=1 for a throw-away in-memory DB)
cd backend && python -m venv venv && source venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env          # set TEACHER_TOKEN!
uvicorn app.main:app --host 0.0.0.0 --port 8000

# teacher console
cd frontend && npm install && npm run dev      # VITE_API_BASE_URL=http://host:8000 to point elsewhere
```

## Test it

```bash
cd backend
pytest -q                                   # 43 tests: graph engine, API flow, WS, acoustic, simulator, 93-student room
python -m sim.orientation                   # acceptance study, 13 pre-declared pass/fail criteria (exit code != 0 on failure)
python -m sim.run                           # general sweeps -> sim/out/*.csv
python -m tools.ui_e2e                      # builds frontend, drives Chromium through a 106-phone session (needs Playwright + Chromium)

cd ../mobile/core && npm install && npm test            # 21 unit tests
NP_PYTHON=/path/to/venv/bin/python npm run test:live    # real TS phones against a real server
cd ../app && npm install && npm run typecheck           # app + core typecheck; `npx react-native bundle` for a Metro check
```

## Honest status

Verified in CI-style runs: graph engine, API, simulator results, TypeScript core against a live server, teacher console in a browser.
**Not verified:** anything touching a real radio or real phone: the Kotlin/Obj-C modules have never been compiled or run,
and the simulator's radio parameters (path-loss exponent, shadowing, body loss) are assumptions until measured with the BLE lab
screen + `tools/fit_pathloss.py`. See `docs/V2.md` §8 and `mobile/README.md`.
